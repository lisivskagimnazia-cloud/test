«Помічник електрика» — багатосторінковий навчально-довідковий сайт з калькуляторами та посібниками.

🎯 Мета

Зібрати практичні інструменти та зрозумілі матеріали в одному зручному онлайн-середовищі.

🧩 Архітектура

Розділи сайту організовані в окремі папки, а стилі, JavaScript та графічні ресурси винесені в assets.

🌐 Технології

HTML, CSS та JavaScript. Розміщення — GitHub Pages.
