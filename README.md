# ⚡ Помічник електрика

Професійний багатосторінковий вебсайт з онлайн-калькуляторами та посібниками з електротехніки.

## Структура

- `/calculators/` — електротехнічні калькулятори
- `/guides/` — посібники та довідкові матеріали
- `/about/` — інформація про проєкт
- `/assets/css/` — стилі
- `/assets/js/` — JavaScript та модулі калькуляторів
- `/assets/icons/` — SVG-іконки

## Технології

HTML5, CSS3, JavaScript, SVG, GitHub Pages.

## Розвиток

Плануються калькулятори перерізу кабелю, автоматичного вимикача, падіння напруги, однофазної та трифазної мережі, а також розширений довідник.

## Публікація

Сайт публікується через GitHub Pages з гілки `main`.
