Про сайт

«Помічник електрика» — багатосторінковий навчально-довідковий сайт з онлайн-калькуляторами та посібниками.

🎯 Мета

Зібрати корисні інструменти й довідкові матеріали в одному простому сайті, який зручно використовувати на телефоні та комп'ютері.

🧩 Структура

  • Головна — огляд сайту.
  • Калькулятори — практичні розрахунки.
  • Посібники — навчальні матеріали.
  • Про сайт — інформація про проєкт.

🌐 Технології

HTML, CSS та JavaScript. Сайт розміщується через GitHub Pages і не потребує окремого сервера.

🚀 Розвиток

У майбутньому можна додати більше калькуляторів, пошук по посібниках, категорії, таблиці та інші корисні інструменти.
